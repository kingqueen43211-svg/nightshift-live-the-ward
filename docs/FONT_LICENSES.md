# Bundled font provenance and licenses

NightShift Live bundles three unmodified Latin-subset WOFF2 files so the demo does not depend on a network request to Google Fonts. The binaries were downloaded on 2026-11-01 from the official `fonts.gstatic.com` URLs returned by the Google Fonts CSS API.

## Space Grotesk

- Copyright: Copyright 2020 The Space Grotesk Project Authors (https://github.com/floriankarsten/space-grotesk)
- License: SIL Open Font License 1.1
- Google Fonts metadata: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Upstream project: https://github.com/floriankarsten/space-grotesk
- CSS API request: https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&display=swap
- Bundled file: `dist/assets/fonts/space-grotesk-latin-variable.woff2`
- Delivery source: https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2
- Supported weight axis: 300–700; this project uses 400, 500, 600, and 700.
- SHA-256: `0640890476fc1198ab4de571fb658de443c4d85b66466ec09534a8737ab1ce9d`

## DM Mono

- Copyright: Copyright 2020 The DM Mono Project Authors (https://www.github.com/googlefonts/dm-mono)
- License: SIL Open Font License 1.1
- Google Fonts metadata: https://github.com/google/fonts/tree/main/ofl/dmmono
- Upstream project: https://github.com/googlefonts/dm-mono
- CSS API request: https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&display=swap
- Regular file: `dist/assets/fonts/dm-mono-latin-400.woff2`
  - Delivery source: https://fonts.gstatic.com/s/dmmono/v16/aFTU7PB1QTsUX8KYthqQBA.woff2
  - SHA-256: `e1896b13b2b1bb112fac2f9571bd6c40e118746e77a4511edbf43fbb41bf3e1e`
- Medium file: `dist/assets/fonts/dm-mono-latin-500.woff2`
  - Delivery source: https://fonts.gstatic.com/s/dmmono/v16/aFTR7PB1QTsUX8KYvumzEYOtbQ.woff2
  - SHA-256: `9964608a849396bd00c4bfd7034afe03486469dcf20b4f6b8cbdfdd310369951`

All three files have the required WOFF2 `wOF2` signature. The subsets include basic Latin, Latin-1, common punctuation, the euro sign, arrows, minus, trademark, replacement character, and the other code points declared by Google Fonts' Latin `unicode-range`. Unsupported code points fall back to the project's system-font stack.
